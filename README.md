# AsesorJAC

Plataforma digital de asesoría tributaria para Juntas de Acción Comunal (JAC)
del municipio de Totoró, Cauca — proyecto de investigación UNAD.

## Módulos

- **Dashboard** — KPIs de cumplimiento tributario y próximos vencimientos
- **Chatbot Tributario** — Asistente con base de conocimiento JAC/DIAN (Ley 2277 de 2022)
- **E-learning** — 4 módulos formativos con evaluaciones interactivas
- **Plantillas Contables** — Libro de Ingresos, Acta de Rendición, Declaración DIAN
- **Calendario Fiscal** — Eventos tributarios con alertas de vencimiento
